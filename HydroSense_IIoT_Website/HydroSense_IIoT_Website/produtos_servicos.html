Processador: Dual-Core 32-bit 240MHz
Protocolos Suportados: MQTT (JSON), Modbus RS485, HTTP
Conectividade: LoRaWAN / Wi-Fi Industrial / Ethernet
Criptografia: TLS 1.2 / SSL (AES-128)
